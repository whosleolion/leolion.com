WEB DESIGN

Build · Design · Administer · Revise

Sites for shows, companies & people

Every site on this page is mine, start to finish — I designed it, built it, and I'm usually still the one keeping it running. Some are for my own work: spy.show has to publicize a show that insists it doesn't exist. Some are for other people's: a new musical needed ticket links and a donate button before rehearsals started, a youth theater needed class registration that wouldn't break every semester. If a project needs a website — a show, a company, a person — I'll design it, build it, and keep it running, custom features included.
