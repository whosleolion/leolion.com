# Science Complete — v0.2 "Phosphor"

Lives at `src/building/sciencecomplete/` (leolion.com/building/sciencecomplete).
No build step: ES modules loaded straight from `index.html`.

## Files

| File | What it is |
|---|---|
| `js/content.js` | **The game.** All text (`WORDS`), items, room maps, and what happens when you examine or talk to things. Lines lifted verbatim from Leo's notes are marked `(notes)`; the rest is draft. |
| `js/engine.js` | State, input, movement, dialogue/choices, close-up + memory transitions, battle, inventory, pause menu, boot/title/ending, save. |
| `js/closeups.js` | The POV close-up scenes (button, microscope, console face, keypad, cabinet, dryer, stall, window, viewfinder, shrink ray, chalkboard, Diane's note), painted with primitives. |
| `js/gfx.js` | Phosphor palette + recoloured atlases, pixel primitives, text, and the CRT presenter (bloom, scanlines, vignette, ghosting, power-off squash). |
| `js/audio.js` | Synthesized chiptune: per-area music, sfx, per-character text voices. No audio files. |
| `assets/` | 1-bit atlases generated by `make_assets.py` here (recoloured to green at load). |

## How the pieces fit

- **Close-ups**: a script calls `closeup('name', async (cu) => { ... })`; the engine zooms into
  whatever you're facing, draws `CLOSEUPS.name`, and your script can `cu.set({...})` to animate it
  or `await cu.interact()` for scenes with their own controls (keypad, viewfinder, note).
- **Memories**: `remember('hatch' | 'diane')` ripples into the classroom map with the memory palette;
  the memory NPC's script calls `forget()` to ripple back to where you were.
- **Glow**: any tile with an `EXAMINE` handler is drawn bright; everything else is dim.

## Tools

    python3 tools/sciencecomplete/make_assets.py --preview /tmp   # rebuild art (+ contact sheets)
    (cd src && python3 -m http.server 8765) &
    node tools/sciencecomplete/playtest.mjs http://localhost:8765/building/sciencecomplete/ /tmp/shots

`playtest.mjs` needs Playwright + Chromium; it plays start to credits with real key presses and
fails loudly if any step (exit code, memories, battle, ending...) doesn't land.
